# Baton Rouge 311 城市公共服务数据

本目录保存从 Baton Rouge 官方 ArcGIS 311 服务中抽取的约 2% 样本，目标数量为 24,000 条。原始服务约有 120 万条记录，因此没有把完整服务下载到本地。

## 文件说明

- `cases_raw.jsonl`：官方接口返回的原始属性，字段名和字段值以数据源为准，保留英文用于追溯。
- `cases_normalized.jsonl`：面向 CivicNexusAgent 业务层的标准化记录，增加中文事项大类、中文状态、关键词和数据集划分。
- `cases_normalized.csv`：标准化记录的表格版本，便于检查和导入。
- `sampling_manifest.json`：数据源地址、采样种子、分层数量、字段列表和抽样结果。
- `download_baton_311.py`：可重复执行的下载脚本。

## 抽样方法

数据按照官方图层和 `ParentType` 事项类别分层，再在每个分层内使用固定种子进行稳定抽样。这样同一份数据可以重复生成，且不会只取接口前几页记录。标准化记录按分层内的 80% / 10% / 10% 划分为 `retrieval`、`validation` 和 `test`。

## 字段使用原则

原始英文居民描述不会被脚本擅自翻译。`raw_text_en` 用于 BGE-M3 的跨语言语义检索；`retrieval_text_zh` 只由已确认的中文事项大类、关键词和状态组成，可供 BM25 做初步中文精确匹配。后续如果需要更强的中文关键词检索，可以对 `retrieval` 划分中的记录单独生成中文摘要和关键词，不需要重新下载原始数据。

脚本不下载几何数据，因为当前项目只需要事项理解、历史案例检索和部门推荐；如果后续加入地图展示，再单独请求 geometry 字段。

## 重新下载

在项目根目录执行：

```powershell
python city_data/download_baton_311.py
```

脚本只覆盖 `city_data` 中由它生成的四个数据文件，不会修改项目中的其他目录。
